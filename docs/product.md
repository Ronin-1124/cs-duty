# cs-duty 产品边界

值班台，不是通用 computer use。真实客户通道只走桌面咚咚 + Radxa Linkr（HDMI 截图 + USB HID）。不用京东网页 DOM。

## 要做

1. **首应**：用真人客服账号尽快回一句，避免平台因未响应扣费。默认填草稿，自动发送单独开。
2. **收需求 → 飞书同事**：统一字段，推审阅，双向收回结果后再回客户。
3. **资料/咨询 → 飞书知识 agent**：改写成可直接发给顾客的短回复；若标记机密，改走人工同事，有反馈再回。

## 不做

打单、退款、改订单、点京麦经营中心、ShowUI/UI-TARS 逐步猜点。其余 GUI 交给同事。

允许的桌面动作只有：聚焦咚咚、点预录槽位/会话列表行、裁聊天区与订单区读屏、填输入框。禁止点发送，除非显式打开自动发送。

## 动态部分

会话列表、聊天气泡、订单在固定面板矩形里变。列表用区域内 OCR 选人；切人后重读两块屏。客户上下文进 SQLite，不靠模型记坐标。
